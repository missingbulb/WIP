# Cross-language conformance vectors

One algorithm runs in two languages, and these files are what stops them
drifting. Each is generated by the implementation that owns the algorithm and
asserted by every implementation of it, so a change made on one side and not
the other is a red test rather than two products that quietly disagree.

| Vectors | Owner (generates) | Asserters |
|---|---|---|
| `detector-conformance.GENERATED.json` | `packages/setlist_core` — `dart run tool/generate_conformance_vectors.dart` | `packages/setlist_core/test/conformance_test.dart`, `backend/test/detector-conformance.test.js` |

**Changing the laugh detector** — a calibration the owner approved, or a fix to
the algorithm itself — means editing the Dart detector, porting the same change
to `backend/src/detect/laughs.js`, regenerating, and landing the three diffs
together. The regenerated events ride the review like any other expected.
