Claudinite (working name) is an app for comedians to record, segment, manage
and review comedy bits — working on new material is the first use, tracking and
managing existing material is the second. It runs on iOS and Android, across
phone and tablet sizes, from one Flutter codebase.

See [`product-wiki/`](product-wiki/README.md) for market/user/technology
research (first pass run), [`dev/design/`](dev/design/architecture.md) for the
system design, and [`dev/requirements/`](dev/requirements/requirements.md) for
the numbered spec the app is built against — it runs as tests.
